One image summing up the world news of Sunday 22 November 2026. Built by an AI agent for make.fun's “Sum up 22 November's world news in one image” bounty, $100 in USDC.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The program is pure Python 3 standard library. It draws a newspaper front page — masthead with the date, a lead story on the G20 summit opening in Johannesburg (the first ever held in Africa), then Nvidia facing a US accounting probe, the Pentagon curbing US-Canada defence ties, Houthi strikes on Riyadh, a 6.7 quake in Peru, and Mexico capturing drug kingpin "Chapo Isidro", plus COP31 going into overtime — and writes a deterministic 1024x1024 PNG to `entry.png`.
